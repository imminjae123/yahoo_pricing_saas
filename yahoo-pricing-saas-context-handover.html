4. 핵심 아키텍처 결정 사항 (반드시 지켜야 할 룰)

절대 위반 금지
  • 모든 DB 쿼리는 SET LOCAL app.current_tenant_id = '<uuid>' 적용 후 실행 — RLS가 1차 방어선
  • Price_Histories, Audit_Logs는 INSERT ONLY — UPDATE/DELETE 불가 (DB 트리거로 강제)
  • cost, min_margin_*, defensive_price는 VIEWER 역할 응답에서 완전 제외
  • Pricing_Rules.condition은 반드시 JSONB로 저장 — 컬럼 평탄화 금지
  • LINE 알림은 트랜잭션 커밋 후 Redis 큐를 통해 비동기 발송 — 라우터 내 직접 await 금지
  • DATABASE_URL은 반드시 postgresql+asyncpg:// — psycopg2 사용 불가

DB 핵심 컬럼명 (이전 Rakuten 명칭에서 변경됨)

테이블컬럼설명
competitor_productsyahoo_item_codeYahoo! 상품 식별자 (UNIQUE) — polling 키
my_productsyahoo_item_code자사 상품 Yahoo! 코드 (nullable)
tenantsshop_url쇼핑몰 URL (플랫폼 중립 명칭)

룰 엔진 평가 순서 (evaluate_rule)

Step 1: reference_price 결정 — ALL_MAPPED → min(prices), PRIMARY_ONLY → prices[0]
Step 2: raw_price 계산 — rule type + adjustment 적용
Step 3: defensive_floor = cost + min_margin (rule 개별 > 상품 레벨 우선순위)
Step 4: recommended = max(raw_price, defensive_floor)  ← floor 적용
Step 5: if price_ceiling: recommended = min(recommended, ceiling)  ← ceiling 적용

Redis 역할 분리 (DB index 충돌 방지)

DB 0Yahoo! API rate-limit Token Bucket
DB 1Celery/RQ 브로커 — LINE 알림 태스크
DB 2테넌트 정책 메타데이터 캐시

6. 앞으로 해야 할 작업 (우선순위 순)

  • 1
    FastAPI 앱 뼈대 생성 — app/main.py (lifespan, middleware, router include), app/dependencies/auth.py (JWT decode → CurrentUser), app/dependencies/db.py (async_session + SET LOCAL RLS) 다음 작업
  • 2
    Alembic 초기 마이그레이션 — alembic/versions/0001_initial_tables.py 생성 (전체 테이블 CREATE), 이어서 0002 RLS 마이그레이션 실행 다음 작업
  • 3
    Docker Compose로 DB 기동 및 마이그레이션 적용 docker compose up -d db → alembic upgrade head 다음 작업
  • 4
    Auth API 구현 — POST /auth/register (테넌트 + OWNER 생성), POST /auth/login (JWT 발급), GET /auth/me
  • 5
    Products / Competitors API 구현 — CRUD + 경쟁상품 매핑 (ProductMapping)
  • 6
    Rules API + Simulation 엔드포인트 구현 — POST /rules/simulate (stateless, DB 쓰기 없음 — evaluate_rule() 호출만)
  • 7
    크롤러 서비스 구현 — app/services/crawl_service.py: YahooShoppingClient로 경쟁상품 조회 → PriceHistory INSERT + AuditLog INSERT (동일 트랜잭션) + 최저가 갱신 시 LINE 큐
  • 8
    Celery Worker + Beat 스케줄러 — 1시간 주기 크롤 태스크 + LINE 알림 발송 태스크
  • 9
    Jinja2 + HTMX UI — /ui/dashboard, /ui/products, /ui/rules, Chart.js 가격 추이 그래프

8. Yahoo! Shopping API v3 핵심 스펙

항목내용
EndpointGET https://shopping.yahooapis.jp/ShoppingWebService/V3/itemSearch
인증쿼리 파라미터 appid=YAHOO_CLIENT_ID (OAuth 불필요)
주요 파라미터query, results(1-50), sort(+price/-price/-score)
응답 키hits[].name, hits[].price, hits[].url, hits[].code, hits[].seller.name, hits[].image.medium
클라이언트app/services/yahoo.py → YahooShoppingClient (async context manager)
공식 문서https://developer.yahoo.co.jp/webapi/shopping/shopping/v3/itemsearch.html
